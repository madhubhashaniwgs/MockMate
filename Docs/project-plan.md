# AI Career Development Platform

## Project Objective

AI-powered platform that helps users improve their career by analyzing resumes, identifying skill gaps, conducting mock interviews, and generating personalized career roadmaps.

## Main Features

1. User Authentication
- User registration
- User login

2. Resume Management
- Upload resume
- Extract resume information
- Analyze skills

3. AI Resume Analysis
- Resume score
- Identify missing skills
- Provide recommendations

4. AI Mock Interview
- Generate interview questions
- Evaluate answers
- Provide feedback

5. Career Roadmap
- Generate learning roadmap
- Track learning progress

## Technology Stack

Frontend:
- React.js

Backend:
- Node.js
- Express.js

Database:
- PostgreSQL

AI:
- Gemini API
