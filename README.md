# AI Career Development Platform

## Overview

AI Career Development Platform is an intelligent career assistance system designed to help users improve their career growth through AI-powered resume analysis, skill gap identification, mock interviews, and personalized career roadmaps.

The platform analyzes user profiles and provides recommendations to improve skills, prepare for interviews, and plan a suitable learning path.

---

## Main Features

### 1. User Authentication
- User registration
- User login
- Secure user access

### 2. Resume Management
- Upload resume files
- Extract resume information
- Store resume details

### 3. AI Resume Analysis
- Analyze resume content
- Generate resume score
- Identify missing skills
- Provide improvement suggestions

### 4. AI Mock Interview
- Generate interview questions
- Evaluate user answers
- Provide interview feedback
- Generate performance reports

### 5. Career Roadmap Generation
- Create personalized learning paths
- Recommend skills to learn
- Track career progress
